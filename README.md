# Vin'tape

Site one-page de **Vin'tape**, première édition de 24 enceintes-cassettes uniques par l'artiste EAZ.

Site 100 % statique (HTML, CSS, JS vanilla), sans build, déployé par Vercel.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Publier

Chaque push sur `main` déploie en production. Chaque branche ou pull request a sa propre URL de preview.
